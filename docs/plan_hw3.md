# ДЗ3: что зафиксировано до проверок устойчивости

Этот файл закоммичен до того, как измерен хотя бы один клип с добавленным шумом и до пересчёта по
подвыборкам фраз. После этого файл не меняется; всё, что добавлено позже, в отчёте названо отдельно.

## Что анализируется

- **Решение.** Полная однопроходная система `swap_anchor_steer` из ДЗ2: смена инструкции на границе,
  подмена начала контекста (доля 0.6) и сдвиг скрытого состояния (слой 20, α = 0.15). Конфигурация —
  `configs/inpass.yaml`, эксперимент — строки `swap_anchor_steer` в `results/inpass/experiments.csv`.
- **Метрика.** Доля det замороженного детектора ДЗ1, без изменений.
- **Набор.** Оценочный набор ДЗ2: 12 фраз × 4 перехода × 3 сида = 144 клипа (в репозитории он
  называется `test`). На нём det = 98 из 144 (0.681). Для сверки приводятся 36 клипов dev.
- **Что не делается.** Модель, параметры компонентов и константы детектора не меняются, новых систем
  нет. Набор читается, но ничего на нём не подбирается. Следствие записано заранее: после этого разбора
  набор нельзя считать отложенным для любой системы, придуманной по его итогам; ей нужны новые фразы.

## Что уже известно к этому моменту

Из ДЗ2 известны det по переходам и по сидам (0.750, 0.583, 0.708) и то, что пропуски полной системы
на этом наборе — 44 строки с шагом нужного знака и размера, у которых точка смены дальше 0.75 с от
границы, и 2 негодных клипа. При составлении этого плана я посмотрел на тех же 144 строках знак
отклонения точки смены, разбивку по фразам и по длительности частей клипа. Поэтому разбор ошибок
и срезы — разведочные: они описывают эти 144 клипа и ничего не проверяют.

Клипы с шумом не измерялись. Пересчёт по подвыборкам фраз не делался.

## Типы пропусков: правила, а не впечатления

Каждая строка выбранной системы, которую детектор не засчитал, получает один тип по правилу:

| тип | правило |
|---|---|
| `invalid` | клип не проходит проверку речи (WER > 0.20, произнесённая инструкция или длительность > 15 с) |
| `flat` | шаг на границе меньше 0.15 |
| `wrong_sign` | шаг не меньше 0.15, знак не тот |
| `edge_split` | шаг нужного знака и размера; точка смены детектора дальше 0.75 с от границы, а взвешенная оценка точки смены по тому же профилю — не дальше 0.75 с |
| `early_change` | обе оценки ставят точку смены раньше границы больше чем на 0.75 с |
| `late_change` | обе оценки ставят её позже границы больше чем на 0.75 с |
| `other` | остальное (оценки расходятся по разные стороны границы) |

Взвешенная оценка — та, что описана в ДЗ1 и использована в ДЗ2 в анализе чувствительности
(`detect.best_split(..., weighted=True)`). Она служит только для разбиения пропусков на типы; решение
детектора не меняется. Для каждого типа в отчёте приводятся клипы из репозитория, их профили и то,
что о причине проверено по данным, отдельно от того, что остаётся предположением.

## Срезы

Размер группы, det и интервал Уилсона для каждой группы:

- направление перехода (вверх: sad → angry, sad → happy; вниз: angry → sad, happy → sad) и сам переход;
- время от границы до конца клипа, три равные по числу группы;
- время от начала клипа до границы, три равные по числу группы;
- сид;
- фраза;
- размер шага в командную сторону (границы групп 0.25, 0.35, 0.45).

Время после границы связано с направлением (грустная речь медленнее), поэтому эти два среза
приводятся и вместе, таблицей направление × время.

## Проверка устойчивости 1: шум во входном аудио

- **Исходное условие.** Выложенные клипы как есть: 144 клипа `swap_anchor_steer` и 108 нулевых строк
  `swap_null` оценочного набора. det = 98 из 144; ложных шагов в нулевых строках 1 из 108.
- **Изменение.** К клипу добавляется белый гауссов шум с отношением сигнал/шум 30, 20, 10 и 0 дБ
  (мощность сигнала считается по всему клипу). Сид шума 0, поток шума свой у каждого клипа и уровня.
  Меняется только это: генератор не запускается, судья, выравнивание, ASR и детектор те же.
- **Что измеряется.** det, число негодных клипов, средний шаг, доля ложных шагов в нулевых строках,
  число строк, у которых решение детектора отличается от решения на чистом клипе.
- **Что проверяет.** Насколько измеренный результат зависит от чистоты записи. Это устойчивость связки
  «клип → судья → детектор», а не генератора: генератор шума не видит.
- **Ожидание.** При 30 и 20 дБ det остаётся в интервале по фразам чистого условия [0.60, 0.76], доля
  ложных шагов не больше 0.10, негодных клипов не больше 0.10. Если так, результат ДЗ2 считаю
  устойчивым к шуму такого уровня. Для 10 и 0 дБ ожидания нет: значения приводятся как есть.

## Проверка устойчивости 2: другие сиды и другие подвыборки фраз

- **Исходное условие.** det по всем трём сидам и всем 12 фразам: 98 из 144.
- **Изменение.** (а) Каждый сид по отдельности. (б) Каждая из 12 подвыборок без одной фразы.
  (в) Каждое из 924 разбиений 12 фраз на две половины по 6: det на половине. Рендеры те же.
- **Что измеряется.** Разброс det: минимум, максимум и доля подвыборок, на которых det ≥ 0.50
  (порог H2d из ДЗ2) и на которых полная система выше каждой из двух систем с одним компонентом.
- **Ограничение, известное заранее.** Это пересчёт по имеющимся рендерам. Генерация с новым сидом
  и новые фразы потребовали бы рендера; если он будет сделан, он будет описан отдельным файлом,
  закоммиченным до рендера.
- **Ожидание.** det ≥ 0.50 на каждой подвыборке без одной фразы и не меньше чем на 95% половин.
