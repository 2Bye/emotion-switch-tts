# Тестовый набор: что зафиксировано до рендера

Этот файл закоммичен до того, как отрендерен хотя бы один клип тестового набора. Время коммита и
время рендера (поле времени в журнале рендера) можно сравнить. После рендера файл не меняется;
всё, что добавлено позже, в отчёте названо разведочным.

## Что известно к этому моменту

Результаты на dev и val (README, п. 6) уже получены: baseline 0 из 36 и 0 из 48, референс 16 из 24
и 30 из 48. Гипотеза ниже сформулирована с их знанием. Проверяется она на текстах, которых нет ни
в dev, ни в val, ни в обучающих манифестах модели (24 предложения: 0 точных совпадений
и 0 вхождений в 446 обучающих и 47 валидационных текстах, проверено на узле до коммита).

## Набор

`configs/phrases/test.json`: 12 фраз из двух предложений, 6–9 слов в предложении. Тексты написаны
для этого набора. В них нет цифр, числительных, слов инструкции и слов с разным британским
и американским написанием. Слово, с которого начинается второе предложение, встречается во фразе
один раз.

## Прогоны

Список в `configs/baseline.yaml`, ключ `planned_runs`. Сиды 42, 43, 44.

| прогон | набор | что в нём | клипов на сид |
|---|---|---|---|
| `inline` | test | baseline (4 перехода), контроль одной эмоцией (3), без инструкции (1) | 96 |
| `stitch` | test | референс (4 перехода) и те же строки без смены | 96 |
| `stitchnull` | test | склейка двух сегментов одной эмоции (3 эмоции) | 36 |
| `stitchnull` | heldout, p2a | то же на val и dev | 12 и 9 |

Модель, параметры декодирования и код рендера те же, что у выложенных прогонов. Перерендеров нет:
выкладывается каждый отрендеренный клип, неудачные считаются.

## Правила измерения

Константы детектора не меняются: |Δ| ≥ 0.15, знак совпадает с заказанным, точка смены не дальше
0.75 с от границы, не меньше трёх окон с каждой стороны.

Два правила на тестовом наборе отличаются от использованных на dev и val. Оба введены по итогам
проверки работы и зафиксированы здесь.

1. **Граница одна для обеих систем.** У каждого клипа, включая склейку, граница — начало первого
   слова второго предложения по принудительному выравниванию. Время стыка по построению
   у склейки приводится как вторичный вариант.
2. **Годность клипа.** Клип годен, если WER его расшифровки не больше 0.20, в расшифровке нет слов
   инструкции и длительность не больше 15 с. Негодный клип считается как «смены нет» у обеих
   систем; число негодных приводится.

Единица вывода — фраза (12). Для каждой фразы считается доля det по 12 строкам системы
(4 перехода × 3 сида). Основной критерий — двусторонний знаковый тест по фразам для разности
«референс − baseline», α = 0.05. Интервалы — бутстреп по фразам; интервал Уилсона по строкам
приводится как описательный.

## Гипотеза H1

На тестовом наборе:

- det baseline ≤ 0.10;
- det референса ≥ 0.50;
- знаковый тест по фразам даёт p < 0.05 в пользу референса.

H1 отвергается, если не выполнено хотя бы одно из трёх.

## Контроль ложных шагов

Для строк без смены (контроль одной эмоцией, без инструкции, склейка одной эмоции) считается доля
клипов с |Δ| ≥ 0.15 и точкой смены у границы. Ожидание: не больше 0.10 для каждого вида.
Если у склейки одной эмоции доля выше 0.10, в отчёте будет сказано, что det референса завышен
шагами, которые создаёт сам стык, и на сколько.

Прогоны `stitchnull` на dev и val разведочные: эти наборы уже использованы.

## Что останется разведочным

Чувствительность к порогам, согласие решений между сидами, разбор по переходам, сравнение
с условиями, отброшенными при импорте исходных прогонов.
